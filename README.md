## Overview

### The challenge

Users should be able to:

- Add their email and submit the form
- See a success message with their email after successfully submitting the form
- See form validation messages if:
  - The field is left empty
  - The email address is not formatted correctly
- View the optimal layout for the interface depending on their device's screen size
- See hover and focus states for all interactive elements on the page

### Continued development

In this project, I refreshed and solidified several key frontend development concepts:

- **Responsive Web Design:** Practiced implementing responsive layouts across **3 distinct breakpoints** (desktop, tablet, and mobile) using CSS media queries and flexbox to ensure proper scaling and positioning.
- **DOM Manipulation:** Re-implemented event handling, dynamic class toggling (`classList.add`/`classList.remove`), and updated text content dynamically to transfer user data from the form to the success state.
- **Form Validation:** Reinforced building client-side form validation logic in JavaScript to catch empty inputs or improperly formatted email addresses before form submission.
